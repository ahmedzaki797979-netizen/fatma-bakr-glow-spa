FATMA BAKR GLOW SPA - WhatsApp Ready

1) Deploy this folder as a Render Web Service.
2) Add environment variables in Render: WHATSAPP_ACCESS_TOKEN, WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_TEMPLATE_NAME, WHATSAPP_TEMPLATE_LANGUAGE, WHATSAPP_VERIFY_TOKEN, REMINDER_SEND_TIME.
3) Webhook URL: https://YOUR-SERVICE.onrender.com/webhook
4) Verify Token: use the same value as WHATSAPP_VERIFY_TOKEN.

Never commit or share the access token.
