الموجود:
1. واجهة احترافية Responsive للكمبيوتر والآيفون والموبايل.
2. لوحة رئيسية وإحصائيات.
3. حجوزات: اسم، هاتف، خدمة، سعر، تاريخ، وقت، حالة، ملاحظات، موعد جلسة تالية.
4. تذكيرات بعد يوم/3 أيام/أسبوع/أسبوعين أو يدوي.
5. العملاء + بحث.
6. المواعيد + بحث وفلترة.
7. الخدمات والأسعار.
8. التقارير والإيرادات وأكثر الخدمات حجزاً.
9. تغيير ألوان الواجهة.
10. اتصال وواتساب يدوي.
11. تصدير واستيراد نسخة احتياطية.
12. إشعارات الجهاز.
13. خادم Node.js اختياري.
14. تسجيل دخول وصلاحيات Admin/Staff كأساس للنظام متعدد الموظفين.
15. API للحجوزات والخدمات والنسخ الاحتياطي.
16. WhatsApp Cloud API جاهز للتذكير التلقائي.
17. عامل خلفي يفحص التذكيرات كل دقيقة.
18. منع تكرار رسالة الواتساب.
19. نسخ احتياطية يومية على الخادم.
20. فحص صحة النظام /api/health.

تشغيل الكمبيوتر/السيرفر:
- ثبّت Node.js 18 أو أحدث.
- انسخ .env.example إلى .env وضع بيانات Meta.
- شغّل: node server.js
- افتح: http://localhost:3000

لأول تشغيل للنظام متعدد المستخدمين، أنشئ حساب المدير عبر API /api/setup (مثال من Postman/curl):
POST /api/setup
{"name":"admin","password":"غيّرها"}

مهم:
الإرسال التلقائي عبر واتساب يتطلب حساب WhatsApp Business/Meta وقالب Utility معتمد، ولا يمكنني وضع بيانات الحساب الحقيقية من عندي.
للاستخدام الحقيقي من عدة أجهزة خارج المركز، استضافة server.js وقاعدة بيانات على سيرفر/Cloud مطلوبة، ويمكن لاحقاً استبدال JSON بقاعدة PostgreSQL دون تغيير الواجهة.
